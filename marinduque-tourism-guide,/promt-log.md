# Task 1 — Sector Selection

Sector:Tourism and Cultural Innovation

Local Challenge: Tourists who visit Marinduque may have difficulty finding information about local tourist destinations in one place.

Target Users: Tourists, visitors, and local residents.

Proposed Project: Marinduque Tourism Guide

Key Features:
1. Display tourist destinations in Marinduque.
2. Search for destinations by name.
3. Show a short description and basic information about each destination.

Proposed Solution: The Marinduque Tourism Guide is a simple website that provides visitors with accessible information about selected tourist destinations in Marinduque.
